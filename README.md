# MemoryCard
🧠 Memory Card

Небольшая интерактивная игра-викторина, созданная на Python с использованием библиотеки PyQt5.

Описание

Программа задает пользователю вопросы и позволяет проверить свои знания. Пользователь отвечает на вопросы, получает обратную связь и может учиться в интерактивном формате.

Технологии

- Python
- PyQt5

Запуск

Для запуска игры необходимо установить библиотеку:

"pip install PyQt5"

После установки запустить файл игры через Python.

О проекте

Учебный проект, созданный для практики программирования на Python и разработки графических интерфейсов.
